# 🕵️ Price Hunter – фронтенд

> Система мониторинга цен с Wildberries.  
> Отслеживайте динамику цен, получайте уведомления, сравнивайте товары и читайте AI-рекомендации.

## 🚀 Демо

- **Сайт (Vercel):** [price-hunter-client.vercel.app](https://price-hunter-client.vercel.app)
- **Репозиторий:** [github.com/Sw1ftFox/price-hunter-client](https://github.com/Sw1ftFox/price-hunter-client)

## 📦 Стек технологий

| Категория        | Технологии               |
| ---------------- | ------------------------ |
| Язык / фреймворк | React 19, TypeScript     |
| Сборка           | Vite                     |
| UI‑библиотека    | Ant Design 6             |
| Стейт‑менеджмент | Zustand                  |
| Маршрутизация    | React Router 7           |
| HTTP‑клиент      | Axios                    |
| Графики          | Recharts                 |
| Тестирование     | Vitest                   |
| CI/CD            | GitHub Actions + Vercel  |
| Стили            | SCSS + CSS Modules       |

## 🛠️ Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/Sw1ftFox/price-hunter-client.git
cd price-hunter-client

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать продакшен‑версию
npm run build

# Предпросмотр собранного проекта
npm run preview
```
