# 🕵️ Price Hunter – фронтенд

> Система мониторинга цен с Wildberries. Отслеживайте динамику цен, получайте уведомления в телеграм‑боте, сравнивайте товары, просматривайте прогнозы и AI‑рекомендации.

![Превью приложения](PriceHunterPreview.png)

## ✨ Основные возможности

- **Мониторинг цен** – отслеживание динамики цен на товары Wildberries.
- **Уведомления** – интеграция с телеграм-ботом для оповещений о снижении цены.
- **Сравнение товаров** – сравнение характеристик и графиков цен нескольких товаров.
- **Прогнозы** – прогнозирование цены на основе истории.
- **AI‑рекомендации** – рекомендации по покупке на основе анализа.
- **Авторизация** – защищённые маршруты, токены.
- **Адаптивный дизайн** – корректное отображение на всех устройствах.

## 🛠️ Установка и запуск

```bash
git clone https://github.com/Sw1ftFox/price-hunter-client.git
cd price-hunter-client
npm install
npm run dev
```

## 📂 Структура проекта (основные модули)

```
src/
├── app/           # Глобальные провайдеры, роутинг, стили, типы
├── features/      # Zustand‑сторы (auth, compare, products, recomendations)
├── pages/         # Страницы (авторизация, сравнение, детали товара)
├── shared/        # UI‑компоненты, хуки, утилиты, тесты
├── widgets/       # Более крупные компоненты (модалки, графики, карточки)
└── main.tsx       # Точка входа
```
